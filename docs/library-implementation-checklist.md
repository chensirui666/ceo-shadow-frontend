# Library 前端实现核对表

## 已确认

- 本次只实现前端；独立 worktree `.worktrees/library`，分支 `codex/library`。
- 依据本地 Library PRD v0.3，沿用现有 UI 设计语言。以下用户确认覆盖 PRD 中的不同表述。
- 搜索仅匹配文件名称。搜索框无占位文案；通过无障碍名称说明用途。
- 格式按大类筛选：文档、表格、演示、图片、代码；保留全部及其他文件。分类与具体格式的预览能力分开，分类不代表新增格式预览承诺。
- 文件正在发送时禁止删除，菜单中的删除项置灰。
- 支持预览：PDF、Markdown、TXT、DOCX、XLSX、CSV、PPTX、PNG、JPG、WebP、GIF、SVG、HTML、JSON/Python/JS 等文本代码文件。
- HTML 隔离展示，不执行文件脚本。
- 常见格式之外的正式文件仍收录，支持下载、重命名、删除；不能静默丢弃。
- 文件列表不显示来源，按格式图标、名称、留白、实际格式、完整日期（YYYY-MM-DD，用户时区）、更多操作排列。
- 来源位于右侧只读预览面板，点击回到具体来源；不能仅跳转模块首页。
- 当前只有 Message 和 Routine 两类来源；用户确认暂时没有日常对话页面，不新增该页面或对应来源选项。
- 预览保留原 PRD 的独立滚动、切换清空旧内容、关闭保留列表状态、错误重试及下载规则。
- Library 交互控件统一使用 HeroUI；搜索框为白色并带外阴影；可用删除项为红色，发送中的删除项置灰禁用。
- 重命名在列表行内完成，格式扩展名单独显示且不可编辑；删除使用确认弹窗。
- 清除筛选同时清空搜索词、来源和分类。
- 修改只保留在当前页面会话；切换模块后仍保留，刷新恢复演示数据。不保存到浏览器存储，不新增回收站。
- 用户确认：先完成独立 Library 前端，等另一个 worktree 的 Routine 完成后再合并联调。
