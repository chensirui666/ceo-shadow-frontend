# Routine Implementation Plan

> Execute inline with superpowers:executing-plans; preserve the user's one-decision-at-a-time requirement.

**Goal:** Implement Routine frontend from the PRD and individually confirmed changes.
**Architecture:** Reuse the existing workspace and HeroUI overlays. Separate config/state rules, a replaceable demo service, and presentation. Demo starts without invented scheduled executions; previews and optional sample history remain labelled.
**Tech Stack:** React 19, TypeScript, HeroUI 3, existing CSS, Node test runner.
**Spec:** `docs/routine-implementation-checklist.md`, `doc/Routine PRD.md`, `DESIGN.md` and the approved PDF sample.

## Constraints

- Only Routine frontend; no Library page or actual generation, scheduler or delivery.
- Two content templates, weekdays multiselect, 48 half-hour time options, creation timezone preserved, recipients optional.
- PDF/MD/Word, three approved styles, PDF/Edition defaults.
- Failed writes retain drafts; edited prompts update topics on save; unadded topic input is ignored by save; preview never creates a formal record.
- Preserve current work and existing navigation; no push or merge.
