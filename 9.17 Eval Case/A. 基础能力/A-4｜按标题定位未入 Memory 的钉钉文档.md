# A-4｜按标题定位未入 Memory 的钉钉文档

**1. 来源与业务背景**

《Relevance AI 定价策略调研》存在于钉钉文档中，但没有导入当前小陈身份的 Memory。用户明确给出标题，只要求找到这篇文档。

**2. 测试目标**

- 主要 Agent 维度：工具使用与状态变更、检索与证据 Grounding。
- 核心判断：Agent 能否根据用户明确给出的标题，从钉钉定位并读取目标文档，而不是把 Memory 当作唯一资料来源。

**3. 初始状态**

- 提问者身份和正式角色：市场部同事。
- 会话状态：当前私聊没有此前对话；《Relevance AI 定价策略调研》未导入当前小陈身份的 Memory，钉钉中存有该文档。

**4. 用户输入**

- 用户原话：“帮我找一下《Relevance AI 定价策略调研》这篇文档。”

**5. Must（必须发生）**

1. 在钉钉中定位标题为《Relevance AI 定价策略调研》的目标文档。
2. 读取目标文档，确认返回的内容与用户指定标题对应。
3. 向当前会话明确说明已经找到该文档。

**6. Must Not（绝对不能发生）**

1. 不将 Memory 未命中误报为文档不存在。
2. 不用名称相近但非目标的文档替代。
3. 不在未读取目标文档时虚称已找到。
4. 不提前总结文档内容。

**7. Hard Gate**

出现以下任一行为，整条 Case 直接失败：

1. 将错误文档或不存在的文档说成《Relevance AI 定价策略调研》。
2. 未定位并读取目标文档，却声称已经找到。

**8. 可观察证据**

- Conversation：“找到了《Relevance AI 定价策略调研》，这份文档目前不在我的 Memory 里，但钉钉中可以正常读取。你需要我继续总结哪一部分吗？”
- Trace：
  1. DWS CLI（doc）→ 按标题定位《Relevance AI 定价策略调研》。
  2. DWS CLI（doc）→ 读取目标文档正文。
  3. DWS CLI（chat）→ 向当前市场部同事私聊发送找到文档的回复。
- 状态回读：发送回执对应当前市场部同事私聊。

**9. 评分说明**

- Case 优先级：P1。
- 允许的其他正确答案或路径：可附文档链接或只说明已找到；但不得在本 Case 中把“找到文档”替换为未经读取的文档摘要。
