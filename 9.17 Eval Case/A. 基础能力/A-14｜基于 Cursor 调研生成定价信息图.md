# A-14｜基于 Cursor 调研生成定价信息图

**1. 来源与业务背景**

产品同事需要用一张图片快速理解 Cursor 的定价结构。Cursor 定价策略调研已导入当前小陈身份的 Memory，Agent 需要生成图片文件并发送给提问者。

**2. 测试目标**

- 主要 Agent 维度：结果与 Artifact 质量、工具使用与状态变更。
- 核心判断：Agent 能否把 Cursor 的文字调研转为事实准确、重点清楚的定价信息图，并将图片发送至当前会话。

**3. 初始状态**

- 提问者身份和正式角色：产品同事。
- 会话状态：当前私聊没有此前对话；《Cursor 定价策略调研》已导入当前小陈身份的 Memory；本 Case 的临时产物目录可通过预置图片生成脚本写入图片文件。

**4. 用户输入**

- 用户原话：“把 Cursor 的定价调研做成一张图片，方便我快速看懂，发给我。”

**5. Must（必须发生）**

1. 生成可打开的图片文件，并发送至当前私聊。
2. 图片说明个人 Pro 的月订阅费为 US$20，且第三方模型月度额度为 US$20。
3. 图片将 Cursor Models 已含容量与第三方模型美元额度明确区分为两个池。
4. 图片说明 BYOK 的模型费用由用户向模型供应商支付，不占用 Cursor 的第三方模型额度。

**6. Must Not（绝对不能发生）**

1. 不把 Cursor Models 的未公开额度写成具体美元值或固定请求数。
2. 不把 BYOK 说成免除 Cursor 订阅费。
3. 不将历史 request-based 套餐规则混入当前定价结构。

**7. Hard Gate**

出现以下任一行为，整条 Case 直接失败：

1. 未生成可打开的图片文件，或未将图片发送至当前私聊。
2. 图片包含 Cursor 调研中不存在的关键额度、套餐或计费结论。

**8. 可观察证据**

- Conversation：“我已经把 Cursor 的定价结构整理成图片发给你了。”
- Trace：
  1. `memory_recall` → 返回 Cursor 定价策略调研内容。
  2. `run_bash` → 调用预置图片生成脚本，在临时产物目录输出 `Cursor 定价结构图.png`。
  3. DWS CLI（chat）→ 向当前私聊发送图片附件。
- Artifacts：`Cursor 定价结构图.png`，可打开，展示 Pro、两个用量池与 BYOK 的关系。
- 状态回读：发送回执对应当前私聊，附件名称与生成文件一致。

**9. 评分说明**

- Case 优先级：P1。
- 允许的其他正确答案或路径：可使用不同配色、版式或图片格式；但必须准确呈现 Pro、两个用量池与 BYOK 的关系。
