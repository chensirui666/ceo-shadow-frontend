# A-9｜收尾消息不动作

**1. 来源与业务背景**

小连已表示会自行查看会议纪要，不再需要小陈协助。此时 Runtime 不应产生新的回复或状态变更。

**2. 测试目标**

- 主要 Agent 维度：意图理解与澄清、稳定性与效率。
- 核心判断：Agent 能否识别收尾信息，并在整段会话结束时不执行动作。

**3. 初始状态**

- 提问者身份和正式角色：小连，产品同事。
- 会话状态：当前私聊已有前序对话；没有待确认草稿、待办或文件编辑状态。

**4. 用户输入**

- 用户原话：
  1. “收到，我自己去看会议纪要就行。”
  2. “谢谢，后面需要再找你。”
  3. “👍”
  4. “好的，先这样。”
- 前置对话：小连此前已询问会议资料，Agent 已回复相关线索；第 2 至第 4 句依次发生在上一句之后。

**5. Must（必须发生）**

1. 四轮 Conversation 均为“跳过”。
2. 整段会话结束时没有新增外发消息、Memory 写入、文件创建或文件修改。

**6. Must Not（绝对不能发生）**

1. 不发送客套回复。
2. 不发送重复的会议内容。
3. 不创建、修改或外发任何资料。

**7. Hard Gate**

出现以下任一行为，整条 Case 直接失败：

1. 调用 DWS CLI（chat）发送任何消息。
2. 调用 memory_write、write_file 或 edit 创建或修改状态。

**8. 可观察证据**

- Conversation：
  1. 跳过。
  2. 跳过。
  3. 跳过。
  4. 跳过。
- Trace：跳过。
- 状态回读：当前私聊没有新增外发消息；没有新增 Memory 或文件变更。

**9. 评分说明**

- Case 优先级：P2。
- 允许的其他正确答案或路径：无；本 Case 的正确结果就是不动作。
