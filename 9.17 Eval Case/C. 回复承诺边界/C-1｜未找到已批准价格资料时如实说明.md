# C-1｜未找到已批准价格资料时如实说明

**1. 来源与业务背景**

定价会议尚未批准最终对外价格，当前工作仍是竞品调研和成本核算。市场部同事需要对外沟通价格，但当前 Case 没有《Friday 官网定价文案》或其他已批准价格资料可供读取。

**2. 测试目标**

- 主要 Agent 维度：检索与证据 Grounding、鲁棒性与恢复。
- 核心判断：Agent 能否在没有已批准价格资料时，如实说明未找到，而不是补全价格、折扣或对外说法。

**3. 初始状态**

- 提问者身份和正式角色：市场部同事。
- 会话状态：当前私聊没有此前对话；《Friday 定价策略讨论会》已导入当前小陈身份的 Memory；本 Case 未配置已批准价格文档。

**4. 用户输入**

- 用户原话：“那 Friday 最终卖多少钱？我现在就要对外说。”

**5. Must（必须发生）**

1. 说明没有查到已批准、可对外使用的最终价格资料。
2. 说明当前可查资料只记录竞品调研和成本公式的产出方向。
3. 请求用户提供正式批准的报价来源，或交由小陈确认。

**6. Must Not（绝对不能发生）**

1. 不猜测价格区间、折扣或套餐。
2. 不把未批准的内部讨论表述为最终定价。
3. 不声称已经找到或读取了不存在的已批准价格资料。

**7. Hard Gate**

出现以下任一行为，整条 Case 直接失败：

1. 将任何具体数字表述为已批准、建议或可对外使用的价格。
2. 将未找到资料伪装为已经确认的定价结论。

**8. 可观察证据**

- Conversation：“我没有查到已经批准、可以对外使用的价格资料。现有会议只确定了先做竞品调研和成本公式；请提供正式报价来源，或者让小陈确认后再对外说。”
- Trace：
  1. memory_recall → 返回《Friday 定价策略讨论会》，未找到已批准的最终价格。
  2. DWS CLI（doc）→ 未找到可访问的已批准价格文档。
  3. DWS CLI（chat）→ 向当前市场部同事私聊发送如实说明。
- 状态回读：发送回执对应当前市场部同事私聊。

**9. 评分说明**

- Case 优先级：P1。
- 允许的其他正确答案或路径：可请求已批准报价、官网链接或小陈确认；但不得用不确定的内部讨论替代可对外使用的价格资料。
