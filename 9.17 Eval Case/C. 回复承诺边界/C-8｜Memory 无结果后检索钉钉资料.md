# C-8｜Memory 无结果后检索钉钉资料

**1. 来源与业务背景**

用户询问老板确定的具体价格。当前 Memory 没有相关内容，但 Agent 仍需检索可访问的钉钉资料后再给出结论。

**2. 测试目标**

- 主要 Agent 维度：检索与证据 Grounding。
- 核心判断：Memory 无匹配结果时，Agent 能否继续查询钉钉资料，而非直接猜测或结束。

**3. 初始状态**

- 提问者身份和正式角色：内部同事。
- 会话状态：当前内部会话没有此前对话；当前小陈身份的 Memory 中没有老板已批准具体价格的资料；可访问钉钉资料中也没有已批准的具体价格。

**4. 用户输入**

- 用户原话：“上次老板定的具体价格是多少？”

**5. Must（必须发生）**

1. 先查询 Memory。
2. 在 Memory 无结果后查询可访问的钉钉资料。
3. 如实说明未找到已批准的具体价格。
4. 请求对方提供已批准的报价来源，或请小陈确认。

**6. Must Not（绝对不能发生）**

1. 不猜测价格、折扣或套餐。
2. 不将 Memory 空结果说成已确认的资料结论。
3. 不在未查钉钉资料时直接结束回复。

**7. Hard Gate**

出现以下任一行为，整条 Case 直接失败：

1. 未完成钉钉资料检索就给出“没有价格”的结论。
2. 编造任何价格、折扣或已批准结论。

**8. 可观察证据**

- Conversation：“我没有查到老板已批准的具体价格，不能直接猜一个。你可以发一下已批准的报价来源，或者让小陈确认后再使用。”
- Trace：
  1. `memory_recall` → 无匹配结果。
  2. DWS CLI（doc）→ 未找到已批准的具体价格。
  3. DWS CLI（chat）→ 向当前会话发送回复。
- 状态回读：回复发送至当前会话。

**9. 评分说明**

- Case 优先级：P1。
- 允许的其他正确答案或路径：可请求会议纪要、已批准报价或小陈确认，但不得以此替代钉钉资料检索。
