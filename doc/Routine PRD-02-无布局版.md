## 1. 背景与目标

用户从推荐区添加 Routine，配置需要生成的内容、开始生成时间、格式及推送对象。Friday 按日程生成简报，发送到用户指定的群聊或个人，并将正式生成的文件收录至 Library。

用户只需管理“生成什么、何时生成、发送给谁、使用什么格式”。本 PRD 不定义 Agent 内部检索、工具调用、调度实现或推理策略，也不将规划能力描述成已实现能力。

## 2. 依据与术语

### 2.1 产品依据

- 用户在本次讨论中确认的规则优先于旧 PRD 的冲突内容。
- 已拉取钉钉最新原文：[Message](https://alidocs.dingtalk.com/i/nodes/m9bN7RYPWdbednwAijXE2v45JZd1wyK0)、[Onboarding](https://alidocs.dingtalk.com/i/nodes/mExel2BLV5xpQm0wsp3z7jQRWgk9rpMq)、[Settings](https://alidocs.dingtalk.com/i/nodes/P7QG4Yx2JpEnpRkgiqXmPPaG89dEq3XD)。原文与差异见[同步记录](sources/dingtalk-2026-09-12/README.md)。
- Skills、Webhook、分享链接、团队复制、邮件专属配置等不纳入本期。
- 本文标注“建议”的内容尚未经单独确认，其余为已确认规则或对已确认交互的具体展开。

### 2.2 三类模板

| 名称 | 含义 | 关系 |
| --- | --- | --- |
| Routine 模板 | 推荐区中可添加的自动化能力，首发称为“早间简报” | 同一个模板可重复添加 |
| 日程实例 | 用户添加后形成的独立 Routine，拥有自己的内容、时间和推送配置 | 修改或删除一个实例不影响其他实例 |
| 内容模板 | Settings 中用于填入主题与详细 Prompt 的预设 | 共 8 种，不自动修改执行频率 |
| PDF 样式模板 | 控制 PDF 背景和视觉样式的系统预设 | 仅 PDF 可用，不支持用户上传背景 |

首发 Routine 暂沿用用户提出的“早间简报”名称；名称不限制用户设置下午、晚上或每周、每月执行。是否改名为“定时简报”尚未确认。

### 2.3 Connector 与内容边界

- 同一 Friday 用户可同时连接多个不同 Connector，每种 Connector 只连接一个账号；各自的 Routine 可以同时运行。
- 内容由 Prompt 决定，并按需要召回当前用户有权使用的 Memory，不按 Connector 划分取材范围。
- Connector 在 Routine 推送配置中用于选择渠道和收件人；推送渠道不限制内容来源。
- 一个日程可跨多个已连接 Connector，选择多个群聊和个人。
- 同一日程的所有收件人共用相同文件格式；选择 PDF 时共用相同样式模板。
- 定时生成记录由 Recent Sessions 承载，不因定时触发而自动创建一条外部输入 Message。

## 4. 页面与操作

### 4.1 全局入口

Routine 与 Library 都有 Friday 工作区入口。沿用 Friday 全局 Settings，不新增独立的账号或 Connector 管理入口。

### 4.2 Routine 首页

- 包含推荐模板和我的日程，介绍 Routine 能按安排生成并发送简报。
- 推荐模板提供名称、能力简介和添加操作。首发仅有“早间简报”，不复制模板凑数；添加后仍可重复添加。个性化推荐算法不属于本 PRD。
- 我的日程提供名称、内容摘要、周期与开始生成时间；完整推送配置和文件格式可在 Settings 查看。
- 打开一个日程进入 Recent Sessions；提供“修改设置”和“删除”操作，修改设置进入该实例的 Settings。
- 首次无日程时提示“还没有日程，请添加一个开始”，不展示模拟执行记录。

### 4.3 添加 Routine

- 点击添加后，说明其如何按主题与 Prompt 整理内容、按日程生成、向指定对象发送并将正式文件保存至 Library。
- 基础配置包含日程名称、内容模板、主题、详细 Prompt、执行频率、开始生成时间、推送目标与格式，提供取消及确认添加。
- 名称可编辑，重复添加应有可区分的默认名称，例如“早间简报 2”。此命名方式为建议。
- 主题与 Prompt 沿用详情设置的双向同步规则。
- 确认添加后形成独立日程，不立即生成或发送，按下一次计划时间执行。
- 添加成功后回到首页，我的日程出现新实例；失败保留输入，不创建成功假象。
- PDF 样式建议在详情 Template 中进一步设置；未选择时使用默认 PDF 排版。

### 4.4 日程详情

- 提供实例名称与说明，可返回 Routine 首页。
- 包含 Recent Sessions、Settings、Template 三个功能部分；用户可以切换，未保存草稿持续保留，切换不视为离开详情。
- 提供试运行、保存、删除三个实例操作。
- 保存作用于整个实例草稿，包括名称、内容、日程、目标、格式与样式，不只作用于当前功能部分。
- 本期不增加尚未确认的暂停能力。

## 5. Settings 功能与字段

包含内容配置、执行安排、Deliver briefing via 与格式。实例名称可编辑。

### 5.1 内容区

内容配置提供内容模板、主题总结与详细 Prompt。主题和 Prompt 同时可见，不做模式切换。提供新增主题输入及 Add 操作；支持直接编辑并确认详细 Prompt。

| 操作 | 页面结果 | 是否正式生效 |
| --- | --- | --- |
| 选择内容模板 | 填入对应主题及完整 Prompt | 否，写入草稿 |
| 输入主题后点击 Add | 更新主题，并同步修改详细 Prompt | 否，写入草稿 |
| 编辑 Prompt 后点击确认 | 更新草稿 Prompt，重新总结主题 | 否，写入草稿 |
| 点击保存 | 保存整个实例配置 | 是，下一次执行使用 |

- Add 和 Prompt 确认是内容同步操作，不等于保存日程。
- 双向同步处理期间显示局部进度；同一时间只提交一个同步操作，避免出现两套不一致的内容。
- 同步失败保留用户输入和上次同步成功的内容，并提供重试；不能显示已同步成功。
- 输入了主题但未 Add，或编辑 Prompt 后未确认时，建议提示先完成同步再试运行／保存，避免使用用户没有看见的另一版内容。
- 已自定义内容后更换内容模板，先提示将替换当前主题与 Prompt；确认后仅替换内容，不改变时间、推送目标、格式或 PDF 样式。
- 主题删除交互尚未单独确认；本版先通过编辑 Prompt 并确认来移除主题，不额外定义独立删除手势。

### 5.2 首期 8 种内容模板

以下为建议的默认主题和 Prompt 文案。均可修改，不构成 Agent 内部执行策略。默认时间范围只是 Prompt 内容，不与日程频率绑定。

| 模板 | 默认主题 | 默认 Prompt |
| --- | --- | --- |
| 每日工作总结 | 今日进展、完成事项、阻塞、下一步 | 请总结今天的工作，按“已完成事项、进行中工作、风险与阻塞、下一步”组织内容。突出重要进展，区分已完成与计划事项。只使用有依据的信息，不编造数据、负责人或期限。 |
| 每周工作总结 | 本周成果、项目进展、风险、下周重点 | 请总结本周工作，按重点项目或工作主题归纳成果、进展、风险和下周重点，避免简单拼接每日记录。区分已经发生的事实与建议行动，不编造数据、负责人或期限。 |
| 每月工作总结 | 月度成果、目标进度、主要问题、下月重点 | 请总结本月工作，整理主要成果、目标进度、关键问题及下月重点。对有依据的目标呈现进展与差距；缺少指标时直接说明，不虚构完成率。 |
| 今日工作简报 | 今日重点、待办、会议、准备事项 | 请整理今天需要关注的工作事项、待办、会议及准备工作，突出有明确截止时间或依赖的行动。优先级必须有依据；不确定的安排需说明，不编造日程。 |
| 项目进展简报 | 重点项目、里程碑、阻塞、下一步 | 请围绕我指定的项目整理近期进展、已完成里程碑、当前风险与阻塞、待协调事项和下一步。未指定项目时，依据已有信息列出当前重点项目；信息不足则明确说明。 |
| 行业洞察 | 行业动态、趋势、影响 | 请围绕我指定的行业总结近期重要动态、趋势与潜在影响，突出变化而非信息堆积。区分事实与分析，重要信息注明可用的时间和来源依据；没有明确行业或资料不足时不要猜测。 |
| 竞品动态简报 | 产品变化、功能更新、定价、市场动作 | 请跟踪我指定的竞品，整理近期产品、功能、定价及市场动作中的实际变化，说明可能的影响。注明已知时间和来源，区分已发布事实与推测；没有指定对象时不要自行编造竞品名单。 |
| 客户跟进简报 | 沟通进展、未答问题、承诺、下一步 | 请围绕我指定的客户整理近期沟通进展、尚未回答的问题、已作出的承诺及下一步。区分客户诉求、我方已确认承诺与建议，不编造负责人或期限。 |

建议提供 8 种内容模板及各自的描述，无须另建完整内容模板市场。行业、竞品、项目、客户等关注对象通过主题或 Prompt 调整，不新增额外业务配置表单。

### 5.3 日程设置

| 字段 | 行为 |
| --- | --- |
| 执行频率 | 建议首期支持每天、每周、每月 |
| 星期 | 每周显示，可选择一周中的执行日；是否多选尚未确认，建议首期单选 |
| 日期 | 每月显示；建议提供 1–28 日及“每月最后一天”，避免无对应日期的歧义 |
| 开始生成时间 | 含义为开始生成，不承诺在该时间送达 |
| 时间说明 | 显示“将在所选时间开始生成，完成后自动发送” |
| 时区 | 建议默认使用创建时用户时区，并显示具体时区，避免出差后静默改变日程 |

- 不提供取材时间范围字段；取材时间范围完全由 Prompt 控制。
- 选择“每周工作总结”不会自动把频率改成每周。
- 新配置从下一次执行生效；已经开始的执行保持启动时配置。
- 未保存草稿不影响原日程，它仍按上次保存配置执行。

### 5.4 Deliver briefing via

先选择已连接 Connector，再通过选择弹窗搜索群聊或个人、选择多个发送对象，并取消或确认选择。

- 已连接 Connector 均可选择；可按群聊／个人查找并多选对象。
- 名称相同的对象展示可供辨认的辅助信息，不让用户凭名字猜测。
- 确认选择后汇总到 Settings，以渠道名称和对象摘要展示；点击“编辑”重新打开选择弹窗，可增删该渠道的群聊和个人，也可继续添加其他 Connector。
- 同一 Connector 下的同一目标去重；跨 Connector 的对象分别显示。
- 目标列表加载失败提供重试，不显示模拟对象；取消弹窗不修改原有目标。
- 无已连接 Connector 时提示去 Friday 全局设置连接。
- 建议正式保存／添加至少要求一个有效推送目标；试运行不需要推送目标。
- 多目标共用格式和 PDF 样式；需要不同格式时，重复添加一个独立日程。

### 5.5 文件格式

- 单选 PDF、MD、Word、PNG；Word 指可下载的 `.docx` 文件，MD 指 `.md` 文件。
- 格式作用于同一次正式生成及其全部推送目标。
- 建议默认 PDF；用户选择其他格式时保留其内容配置。
- 文件较长时 PNG 的分页／多图规则尚未确认，不默认承诺一张无限长图。

## 6. Template

- PDF 格式下提供系统预设样式的名称、选择和预览，明确当前选择。
- 选择样式只更新草稿；可打开及关闭放大预览，预览不等于保存，正式生效仍通过保存操作。
- 样式控制视觉呈现，不改变内容主题、Prompt 或执行时间。
- 不支持上传背景或自定义模板编辑器。
- 未选择样式时建议采用默认 PDF 排版。
- 非 PDF 时提示“切换为 PDF 后可使用样式模板”，提供“切换为 PDF”操作；切换写入草稿，保存后才正式生效。非 PDF 时不允许选择样式，PDF 状态下不显示该切换提示。
- 从 PDF 切换其他格式时，建议保留原样式选择但不应用；切回 PDF 后恢复选择。
- 系统样式的具体数量、名称和素材由设计补齐，不在本版虚构已上线样式。

## 7. 试运行、保存与离开

### 7.1 试运行

1. 使用当前同步完成的草稿内容及所选格式／样式生成预览，无须先保存正式配置。
2. 点击后展示生成中状态，防止重复提交。
3. 完成后打开预览层，显示生成文章内容；关闭后回到详情并保留草稿。
4. 不发送给任何对象，不改变日程，不纳入 Library。它是正式文件全收录规则的例外。
5. 生成失败或资料不足时显示原因并允许返回修改；不展示空白文件为成功结果。
6. 建议 Recent Sessions 仅列正式执行，试运行结果保留在当前预览中，避免与正式发送记录混淆。

### 7.2 保存

- 保存整个实例配置；有未确认的 Prompt 编辑或主题同步进行中时先提示完成同步。
- 保存成功后草稿成为正式配置，后续执行使用新配置。
- 保存失败保留草稿及原正式配置，用户可重试。
- 已经开始的执行不受本次保存影响。

### 7.3 有未保存修改时离开

仅在用户有未保存修改、准备离开详情时弹出，不在每次字段修改时打断。

提示标题为“有未保存的修改”，文案为“保存后，后续日程才会使用当前配置；未保存时仍按原配置执行。”提供取消保存、保存及关闭（×）操作。

| 操作 | 结果 |
| --- | --- |
| 取消保存 | 放弃本次全部未保存修改，恢复原配置，并继续原定离开动作 |
| 保存 | 保存成功后继续离开；校验或保存失败则保留草稿，停留详情 |
| × | 关闭弹窗，留在编辑页面，保留未保存修改 |

返回首页、切换到 Library／Message 等页面属于离开；切换详情内部功能部分 不属于离开。应用关闭是否能拦截取决于宿主能力，不承诺无法实现的关闭保护。

## 8. Recent Sessions

### 8.1 执行记录

按开始生成时间倒序提供正式执行记录，包括开始时间、标题和结果摘要。打开某次执行后可查看生成内容、文件、逐目标发送结果、失败原因及适用的重试操作；返回后保留之前的浏览位置。

未执行过时显示“日程执行后，你可以在这里查看生成内容和发送结果”。

### 8.2 单次记录详情

- 执行信息：日程名称、本次开始时间、触发类型和结果摘要。
- 生成结果：生成内容预览或文件入口；正式文件可跳转 Library 查看。
- 推送结果：按 Connector 分组，逐个显示群聊／个人及其结果。
- 失败时提供可读原因和适用的重试操作。

| 情况 | 显示与操作 | Library |
| --- | --- | --- |
| 正在生成 | 显示生成中 | 未形成文件前无条目 |
| 资料不足 | 记录“本次资料不足，已跳过发送” | 不新增文件 |
| 生成失败 | 显示失败原因 | 未生成文件则不新增 |
| 已生成，正在发送 | 展示文件及发送进度 | 已收录 |
| 全部发送成功 | 显示已发送及目标结果 | 保留文件 |
| 部分发送失败 | 展示逐目标结果，允许仅重试失败目标 | 保留原文件 |
| 全部发送失败 | 展示原因，允许重试失败目标 | 保留原文件 |

- 重试发送复用原文件，不能重新生成或再次发送给已成功的目标。
- 发送结果未知时应明确显示“结果待确认”，不能直接视为失败而重复发送；处理方式留给执行能力定义。
- 同一次生成向多个目标发送只对应同一个文件，不因目标数或重试次数重复收录。

## 9. 删除日程

- 首页与详情中的删除指向同一操作。
- 建议显示确认弹窗：“删除此日程后将停止后续执行，Library 中已有文件会保留。”
- 确认删除后从我的日程移除，不影响同一模板创建的其他实例。
- Library 已生成文件保留，来源标注“原日程已删除”。
- 删除时若已有执行正在进行，其继续生成／发送还是终止尚未确认；本版不将停止后续执行等同于撤销已经开始的动作。

## 10. 关键完整流程

### 添加并正式执行

打开 Routine → 推荐模板添加 → 阅读说明 → 选择内容模板并调整主题／Prompt → 配置开始时间、对象和格式 → 确认添加 → 我的日程出现实例 → 到时开始生成 → 正式文件进入 Library → 向各目标发送 → Recent Sessions 记录各目标结果。

### 修改与试运行

我的日程 → 修改设置 → 更新主题或 Prompt 并完成同步 → 试运行 → 查看预览 → 返回继续修改 → 保存 → 下一次执行使用新配置。试运行不发送、不归档。

### 部分发送失败

文件生成并归档 → 部分对象发送失败 → 查看本次执行详情 → 重试失败目标 → 复用原文件 → 更新失败目标结果，已成功目标不重复发送。
