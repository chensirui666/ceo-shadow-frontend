## 额度用尽后

**More when you need it**

# 三类额度，分别管理

- **Token 流量**：套餐赠送的 Token 流量用完后，可额外充值购买并继续使用；也支持使用用户自己的 API Key。
- **Memory 额度**：用满后，已写入的 Memory 仍可读取；暂停新的 Memory 写入，用户可删除内容或升级套餐。
- **文件存储空间**：用满后，已上传文件仍可访问；暂停上传新文件，用户可删除文件或升级套餐。
